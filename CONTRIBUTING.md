# Guía de contribución

¡Gracias por tu interés en contribuir a este proyecto!

Sigue los siguientes pasos para colaborar de forma ordenada.

## 1. Cómo reportar un error (Bugs)
Si encuentras un error, por favor abre un `Issue` describiendo:
* Una descripción clara del problema.
* Los pasos para reproducirlo.
* El comportamiento esperado frente al obtenido.

## 2. Cómo proponer una mejora (Features)
Si tienes una idea o nueva funcionalidad:
* Abre un `Issue` para discutir el cambio antes de programar.
* Explica por qué sería útil está mejora.

## 3. Checklist para Pull Requests (PR)
Antes de enviar tu `Pull Request`, asegúrate de revisar lo siguiente:
- [x] El código sigue el estilo y las convenciones del proyecto.
- [x] Se han probado los cambios localmente y no generan errores.
- [x] El PR está dirigido a la rama correcta.
